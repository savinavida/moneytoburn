# Деньги на ветер

**«Прикинь заранее, что и почём в твоём приключении! Ведь только тогда будет так красиво и не больно.»**

Ретро-игровой адаптивный калькулятор бюджета путешествий. Работает прямо в браузере на HTML, CSS и JavaScript: сервер, база данных, сборка, регистрация и платные API не нужны.

## Возможности

- Количество путешественников, дней и ночей; необязательное название поездки.
- Пять категорий с авторскими названиями: транспорт, проживание, питание, развлечения и прочее.
- Быстрый ввод — одна общая сумма для категории.
- Подробный ввод — неограниченный список именованных позиций с суммами, редактированием и удалением.
- Отрицательные суммы в подробных позициях для возвратов и скидок.
- Переключение режимов без потери данных: быстрый ввод и подробный список сохраняются независимо, но в расчёт попадает только активный режим. В интерфейсе показано, какой режим учитывается.
- Автоматическое обновление итогов после изменения исходных данных.
- Общий бюджет, стоимость на человека, средние расходы за день и проценты по категориям.
- Круговая диаграмма, игровые сообщения и подтверждаемый сброс.
- «Чек путешественника» с детализацией: печать/сохранение в PDF и скачивание PNG.
- Адаптивная вёрстка, анимация с поддержкой `prefers-reduced-motion`.

Все суммы вводятся в евро и относятся ко всей поездке и всей компании. Пустые категории и пустые подробные списки считаются нулём. Количество путешественников и дней должно быть целым числом больше нуля. Ночи — отдельный параметр и не участвуют в формулах.

## Расчёты

- Общий бюджет = сумма активных сумм пяти категорий.
- На одного человека = общий бюджет / количество путешественников.
- За день = общий бюджет / количество дней.
- Доля категории = сумма категории / общий бюджет × 100%.

Денежные значения и доли округляются до двух знаков. Если общий бюджет равен нулю, доли отображаются как 0,00%. При наличии возвратов круговая диаграмма визуально показывает положительные траты, а легенда сохраняет математическую долю категории относительно итогового бюджета; в таком случае подпись диаграммы уточняет, что показаны положительные траты.

## Режимы ввода расходов

У каждой категории есть переключатель **«Быстро / По пунктам»**.

- В режиме **«Быстро»** учитывается только одно поле общей суммы. Подробные позиции, если они уже были добавлены, сохраняются, но не суммируются.
- В режиме **«По пунктам»** учитывается сумма всех позиций. Поле быстрого ввода сохраняется, но не суммируется.
- Переключение режима не стирает данные. Текущий активный режим и его итог видны в карточке категории.
- В подробном режиме можно добавить, переименовать, изменить или удалить позицию. Отрицательное значение означает возврат/скидку.

В чеке сохранённые подробные позиции также перечисляются, даже если на момент расчёта активен быстрый режим; в таком случае они помечены как не включённые в расчёт.

## Чек путешественника: PDF и PNG

Экспорт доступен после успешного расчёта.

- **PDF:** кнопка открывает системное окно печати браузера. Выберите принтер **«Сохранить как PDF»** (или аналогичный пункт в вашем браузере), затем сохраните файл. В документе используется отдельная печатная версия чека.
- **PNG:** чек рисуется в браузере на HTML Canvas и скачивается как `chek-puteshestvennika.png`.

Сервер и сторонние библиотеки для экспорта не требуются. PDF использует встроенную функцию печати браузера, PNG — стандартный Canvas API. Для корректного PDF включите печать фоновой графики, если браузер предлагает такую настройку.

## Запуск локально

1. Скачайте и распакуйте архив.
2. Откройте `index.html` в современном браузере.
3. Введите параметры поездки и расходы.
4. Выберите быстрый или подробный режим в каждой категории.
5. Результаты обновляются автоматически; кнопка «Рассчитать бюджет» остаётся доступна для явного пересчёта.

Для локальной работы достаточно открыть файл напрямую. При желании можно запустить простой статический сервер, но это не обязательно.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub.
2. Загрузите в корень репозитория `index.html`, `styles.css`, `app.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите **Save**.
6. После публикации GitHub покажет ссылку на сайт в настройках Pages.

## Файлы

- `index.html` — разметка интерфейса, категории и чек.
- `styles.css` — визуальный стиль, адаптивность, анимации и стили печати.
- `app.js` — состояние расходов, проверки, расчёты, диаграмма и экспорт.
- `README.md` — эта инструкция.

## Проверки и ограничения

Проведены проверка синтаксиса JavaScript через `node --check`, проверка структуры HTML на повторяющиеся ID и отсутствие вложенных форм, а также контрольные арифметические расчёты. Попытка автоматического прогона интерактивных сценариев в Chromium в текущей среде завершилась тайм-аутом, поэтому полноценное браузерное E2E-тестирование здесь подтвердить не удалось.

Рекомендуется вручную проверить в браузере добавление/редактирование/удаление позиций, переключение режимов, сброс, печать PDF и сохранение PNG. Экспорт PDF зависит от системного диалога печати браузера. Калькулятор не сохраняет введённые данные после закрытия/перезагрузки страницы.
